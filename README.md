# mb-parcel-history

Per-municipality **historical** snapshot shards for the Manitoba parcel
search webapp's "as-of-year" (historical compare) view. Served as static
files via the free **jsDelivr** CDN — kept here, separate from the main
app repo and its Vercel deploy, so the historical archive never bloats
either.

## Source

Generated by `r/build_historical_shards.R` in the
[manitoba-opendata-parcelsearch](https://github.com/jayschellenberg/manitoba-opendata-parcelsearch)
repo, from the dated provincial open-data snapshots archived locally per
year (MBRollGeoPackage parcels + Manitoba Zoning By-Laws + Development Plan
Designations). All data is Province of Manitoba open data.

## Layout

```
<year>/
  manifest.json            # layer dates + muni list (name + parcel count)
  parcels/<muni_no>.json   # GeoJSON FeatureCollection, simplified (~10 m), EPSG:4326
  zoning/<muni_no>.json
  devplan/<muni_no>.json
```

- **Muni key** is the municipality number (the one field common to all
  three layers). Each feature also carries its own historical attributes
  (`Roll_No_Txt`, `Municipality`, `Muni_Name_With_Typ`, zoning/dev-plan
  designations) as of that snapshot.
- **`manifest.json.layers`** records each layer's own snapshot date — the
  three layers are downloaded on different dates.

## Access (jsDelivr)

Served pinned to an **immutable commit SHA** — never `@main` (branch HEADs
lag on the CDN, and a mutable ref ships any bad/compromised commit straight
to the live app with no review window and no Subresource Integrity):

```
https://cdn.jsdelivr.net/gh/jayschellenberg/mb-parcel-history@<commit-sha>/<year>/manifest.json
https://cdn.jsdelivr.net/gh/jayschellenberg/mb-parcel-history@<commit-sha>/<year>/parcels/<muni_no>.json
```

**Contract:** the app pins one commit SHA (see `web/src/arcgis.js` in the
app repo). Always repoint the app to the new SHA after committing a new
`<year>/`, then push.

## Regenerating / adding a year

Archive a new provincial snapshot, then from the main repo:

```
Rscript r/build_historical_shards.R --year <year>
```

and commit the new `<year>/` folder here.
